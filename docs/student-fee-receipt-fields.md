# Student Fee Receipt — Field List

Issued to a student the moment the Trust approves their scholarship payment (see
`PATCH /:id/payment/approve` in `server/src/routes/applications.js`), generated by
`server/src/studentFeeReceipt.js`. Itemizes the money: course fee, concession, and what
was actually paid.

Numbered sequentially per year, e.g. `NGF/2026/00001`.

## Receipt Details

| Field | Source |
|---|---|
| Receipt No. | Auto-generated, e.g. `NGF/2026/00001` |
| Date | Date the receipt is issued (payment approval date) |
| Application No. | `NGC-{application.id}` (first 8 characters, upper-cased) — same reference format used elsewhere |
| Received from | `application.fullName`, upper-cased for display |
| Course | "Skill Development Program - " + `application.examName` (falls back to `application.college.degree`); only the English half is kept if the stored value still has the wizard's legacy "English / Tamil" format |
| Mobile | `application.mobile` |
| Email | `application.email` |

## Fee Breakdown

The itemized part unique to this receipt:

| Field | Source | Notes |
|---|---|---|
| Course Fee | `application.courseFee` | Original fee before any concession |
| Concession | `getProvisional(application)` (`server/src/scholarshipCalc.js`) — only for `concessionCategory` `category3`/`category4`; otherwise falls back to a single `application.finalApprovedConcession` line | Shown as a breakdown: `Base (<category label>)`, one line per applicable factor (Financial Self-Support, Academic Performance, Tamil Medium, Government School, SC/ST), then `Calculated <sum>% (capped at <cap>% -> <final>%)` (ASCII arrow — the standard PDF font can't render `→`) |
| **Amount Paid** | `payment.amountPaid` | Boxed/highlighted on the receipt |

## Access

- **Admin:** `GET /api/applications/:id/payment/receipt-signed-url` — view/download from the
  Fee Receipt section on the application detail page. `POST /api/applications/:id/payment/receipt/generate`
  retries generation if it failed on approval.
- **Student:** same signed-url endpoint (dual admin/owner access) — "Download Fee Receipt"
  button on the `/payment` page once payment is approved.

*If the generated receipt's layout or fields change, update this list to match
`server/src/studentFeeReceipt.js`.*
