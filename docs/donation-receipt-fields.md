# Donation Receipt — Field List

Issued to a donor the moment an admin marks their donation **verified** (see
`PATCH /api/donations/:id/status` in `server/src/routes/donations.js`), generated by
`server/src/receipt.js`, and emailed to the donor automatically via Resend.

Numbered sequentially per year, e.g. `NGD/2026/00001`.

## Receipt Details

| Field | Source |
|---|---|
| Receipt No. | Auto-generated, e.g. `NGD/2026/00001` |
| Date | Date the receipt is issued (verification date) |
| Received with thanks from | `donation.fullName` |
| Email | `donation.email` |
| Mobile | `donation.mobile` |
| PAN | `donation.pan` (optional — donor submits this only if they need an 80G receipt) |
| Amount (in words) | Donation amount, spelled out — e.g. "Two Thousand Five Hundred Only" |
| **Amount** | `donation.amount`, boxed/highlighted on the receipt |

## Access

- **Donor:** emailed automatically as a PDF attachment once verified (`server/src/email.js`).
- **Admin:** `GET /api/donations/:id/receipt/signed-url` — "View Receipt" link on the
  Donations admin page once issued.

*If the generated receipt's layout or fields change, update this list to match
`server/src/receipt.js`.*
